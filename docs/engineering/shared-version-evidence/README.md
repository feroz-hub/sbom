Reproduce using the existing trusted development certificate:

```sh
# From frontend, with a working Node runtime.
NEXT_PUBLIC_AUTH_ENABLED=true node node_modules/next/dist/bin/next dev \
  --webpack --hostname localhost --port 13001 --experimental-https \
  --experimental-https-key certificates/localhost-key.pem \
  --experimental-https-cert certificates/localhost.pem

# In another terminal, from frontend/e2e.
node node_modules/@playwright/test/cli.js test --config posture.config.ts
```

tablet and mobile views, dark mode, expanded evidence and the shared product
