## Recommended disposable target and W1 design gate

Recommend **D: a schema-only clone of B's observed revision-079 schema in a separate local PostgreSQL 16 instance/container**, populated later with synthetic tenants/users/projects/SBOMs. Use a distinct Compose project (proposed `sbom-uuid-w1`), dedicated volumes, independently provisioned credentials and a distinct loopback-only host port. This is a proposed identity and isolation boundary, not an existing database or approval to create one.
