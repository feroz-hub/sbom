## Definitions used in the inventory

- **Public**: application resource identifiers exposed by routes, schemas or serializers, including authenticated/admin-only surfaces. This does not imply anonymous access, authorization or a promise of globally stable IDs.
- **Internal**: storage, association, audit, cache or configuration identifiers whose main role is implementation identity. An internal hash or reference can still appear in a response; exceptions are noted. Classification is a source-based migration assessment, not an exhaustive API exposure/security review.
- **External**: upstream/domain-assigned identity, such as a CVE identifier or an identity-provider subject. External identifiers beside a local integer PK do not make the PK external.
- **D**: single integer surrogate with SQLAlchemy's implicit autoincrement behavior; no PK callable/default/sequence is declared. PostgreSQL normally generates it via its integer PK sequence convention; SQLite uses INTEGER PRIMARY KEY rowid semantics. Explicit import/seed values remain possible. This is model behavior, not a verification of deployed sequence state.
- **U**: caller-generated UUID4 string; the model itself has no PK default. Call-site references below identify generation.
- **N**: caller-supplied natural/domain key; no row-ID generator.
- **H**: application-derived SHA-256 cache key, not a random surrogate.
- **T**: inherited `tenant_id: Integer NOT NULL`, FK to `tenants.id`, from [app/models_mixins.py:62](../../../app/models_mixins.py#L62). This is an ownership field, not a PK component.
- **None** in the identifier column means no separately declared UUID/public row-ID field found; the PK may itself be public. Names, ordinary FKs, paths and JSON payloads are not automatically alternate identifiers. Listed semantic identifiers/hashes are explicitly distinguished from row IDs.

`TenantOwnedMixin` declares no primary key. `SoftDeleteMixin` (class at [app/models_mixins.py:31](../../../app/models_mixins.py#L31)) declares no PK or ownership field; `deactivated_by` is attribution, not ownership. ## Composite keys, natural identities and special cases

- `source_response_cache` has the sole mapped composite PK: **(source, component_key)**. Both columns participate; neither has a generator. Other composite `UniqueConstraint`/foreign-key/index declarations are not composite PKs. In particular, tenant/id unique pairs do not alter the single-column PKs listed above.
- Main `kev_vulnerabilities.cve_id`, `epss_score.cve_id`, `cve_cache.cve_id` and NVD `cves.cve_id` are **external natural vulnerability identifiers**. They are not database surrogate IDs and are not automatically UUID conversion candidates.
- The separate KEV service declares `kev_vulnerabilities.id` as a BIGINT identity PK and `cve_id` as a unique natural key ([KEV/database.py:39](../../../KEV/database.py#L39)). This conflicts with the main application's mapped PK shape if both are pointed at the same physical table; this audit does not assume they share a database or reconcile them.
- `sbom_component.bom_ref` ([app/models.py:1045](../../../app/models.py#L1045)) is a document-local component reference and is not its database PK; `sbom_component.id` is the database surrogate. UUID-shaped bom-ref values, CycloneDX serial numbers and identifiers embedded in SBOM JSON do not establish a UUID database PK. PURL/CPE and canonical/deduplication keys also remain package/content identities.
- `provider_name` is a semantic natural PK in `ai_provider_config`; `cache_key` hashes identify derived cache entries in `compare_cache` and `ai_fix_cache`. These are distinct from UUID surrogate IDs.
- All three current UUID PKs use `String(36)`, not native SQLAlchemy/PostgreSQL UUID types. Generation occurs in services, not column defaults; the model declarations alone do not enforce UUID4 validity.
- Nullable tenant columns on configuration/advisor models support optional tenant/platform scope; on audit records they can represent attribution and can be cleared by FK delete behavior. They do not imply the same isolation contract as `TenantOwnedMixin`. The inventory records declarations without asserting authorization correctness.
