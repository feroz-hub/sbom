Mock write flow owns one physical connection: READ ONLY preflight and ROLLBACK,
then one READ WRITE transaction. Advisory7160085085, version EXCLUSIVE NOWAIT
(after047), and SHARE NOWAIT locks on all ordinary public tables precede mutation.
The unchanged UUID sources additionally own their target locks. The broad SHARE
window and FK/catalog dependencies require independent approval/live testing.

Run exactly one selected body. For047, finish all558statements before creating
the version table. Validate the full expected post-schema/security/reference
catalog while the marker is still empty/old; only then parameterize the INSERT/
compare-and-update marker, require one RETURNING row/rowcount and sole exact
marker. COMMIT once, record acknowledgment, physically close. The result remains
COMMITTED_UNVERIFIED until a separately authorized new READ ONLY connection
verifies full committed state, rolls back and closes.

Known failure rolls back and closes, yielding ROLLED_BACK_UNVERIFIED pending
independent confirmation. Lost COMMIT acknowledgment is UNKNOWN_COMMIT_STOP,
without rollback/retry/repair. Lost rollback or failed closure remains unverified.
Exceptions retain class/SQLSTATE only; raw arguments/DSNs/secrets are not logged.
A later live evidence adapter must durably flush phase records before mutation
and COMMIT, preserve errors independently from cleanup, and require operator
reconciliation after uncertain outcomes. No automatic recovery is implemented.
